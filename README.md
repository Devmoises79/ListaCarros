## 🚗 ListaCarros — Sistema de Catálogo com POO em Python

# 📌 Visão Geral

Este projeto implementa um sistema simples de catálogo de veículos utilizando Programação Orientada a Objetos (POO) em Python. O objetivo é simular a estrutura de um sistema de seleção de produtos, aplicando conceitos fundamentais de modelagem de dados e lógica de programação.

#🎯 Objetivo Técnico

O projeto foi desenvolvido com foco em:

- Estruturação de classes e objetos
- Encapsulamento básico de dados
- Manipulação de listas de objetos
- Interação via terminal (CLI)
- Lógica condicional para seleção de dados

# 🧠 Conceitos Aplicados

* 🧱 Programação Orientada a Objetos (POO)

- Criação da classe Carro
- Instanciação de objetos com atributos (Marca, Modelo, Ano, Preço)
- Representação de entidades do mundo real no código

# 📚 Estruturas de Dados
- Uso de listas para armazenar objetos
- Acesso indexado para seleção dinâmica de elementos

# 🔀 Controle de Fluxo
- Estruturas condicionais (if/else)
- Validação de entrada do usuário

# 💻 Interação com Usuário

- Entrada via terminal com input()
- Saída formatada com print()

# ⚙️ Funcionamento do Sistema

- O sistema inicializa uma lista de veículos pré-cadastrados.
- O usuário escolhe um carro através de um menu numérico.
- O programa valida a entrada.
- As informações completas do veículo selecionado são exibidas.

# 🏗️ Estrutura do Código

- Carro: classe que representa a entidade do sistema
- Instâncias de carros: objetos com dados reais simulados
- carros[]: lista que armazena os objetos
- Lógica de seleção baseada em índice

# 📊 Perfil do Projeto (Engenharia de Software)

* Este projeto simula um mini-sistema de domínio, aplicando conceitos usados em sistemas reais como:

- Catálogos de produtos
- Sistemas de estoque
- Seletores de inventário
- Estruturas base para e-commerce
